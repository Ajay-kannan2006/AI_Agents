# Edge AI Deployment Packager

This agent provides a web interface for generating a ready-to-build deployment package for an edge AI model. It takes a target framework, model filename, and port, and generates a real Dockerfile, requirements.txt, and inference run script from templates, bundled into a downloadable zip.

## Overview

This project is built for a practical edge-AI workflow: turn a framework choice into an actual working deployment scaffold, instead of writing the same Dockerfile and inference stub by hand for every project.

### What it delivers

- a generated Dockerfile using the correct base image for the chosen framework
- a generated requirements.txt with the correct extra packages for that framework
- a generated run.py inference stub with the correct loading/inference API calls for that framework, ready for a real preprocessing step to be filled in
- a downloadable zip containing all three files
- a short note on the single most important thing to verify before building (e.g. GPU requirement, base image tag currency)

## Architecture

1. The user selects a target framework, model filename, port, and optionally a target device (for documentation only).
2. A template lookup provides the correct base image, extra pip packages, and run-script skeleton for the selected framework.
3. The Dockerfile, requirements.txt, and run.py are generated by string templating — not written by the LLM.
4. All three files are written to disk and bundled into a downloadable zip.
5. Results are shown in the interface as syntax-highlighted previews, alongside the zip download and a short generated note.

## Supported frameworks

| Framework | Base image | Notes |
|---|---|---|
| ONNX Runtime | `python:3.11-slim` + pip install | CPU-only; use `onnxruntime-gpu` with a CUDA base image for GPU acceleration |
| TFLite | `python:3.11-slim` + pip install | `tflite-runtime` wheel availability is platform-specific; check current wheels before relying on this as-is |
| TensorRT | `nvcr.io/nvidia/tensorrt:24.08-py3` | Requires an NVIDIA GPU; run with `docker run --gpus all`; verify the tag is current |
| OpenVINO | `openvino/ubuntu22_runtime:2024.4.0` | Runtime included in the base image; verify the tag is current |

## Run with Docker

### Prerequisites

- Docker installed and running
- a Gemini API key available as `GEMINI_API_KEY`

### Start the app

```bash
cd agent-deployment-packager
docker build -t edge-deployment-packager .
docker run -p 7867:7867 -e GEMINI_API_KEY=your_key_here edge-deployment-packager
```

Open http://localhost:7867 in a browser, select a framework, and click Generate.

## Notes

- Generated `run.py` files include a working model-loading call and a dummy input for a smoke test, but the actual preprocessing logic (matching real sensor input to the model's expected format) must be filled in — this agent scaffolds the deployment, it does not write the full inference pipeline.
- Base image tags (especially for TensorRT and OpenVINO) are pinned to a specific version in the templates and should be checked against the vendor's current registry before a real build, since these are updated independently of this project.
- The container exposes port `7867` by default.
