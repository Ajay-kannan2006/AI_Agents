# Edge AI Toolchain Advisor

This agent checks whether an ONNX model is likely to be compatible with common deployment runtimes such as ONNX Runtime, TensorRT, TFLite, and OpenVINO. It uses a curated operator-support reference and reports framework compatibility from the model graph itself.

## Overview

The app helps answer a deployment question: which runtime is the best fit for this model before an actual conversion step is attempted?

### What it delivers

- the operator types found in the uploaded model
- a compatibility percentage for each selected framework
- a detailed per-operator support table
- a short recommendation based on the computed results

## Architecture

1. The uploaded ONNX model is loaded and validated.
2. The graph is scanned to count each operator type.
3. Each operator is compared against a curated support table for the selected frameworks.
4. A compatibility score is computed for each runtime using a simple weighted method.
5. The scores and operator details are displayed in the interface.
6. A short recommendation is generated by the model-based explanation layer.

## Tech stack

- Python 3.11
- Gradio for the web UI
- ONNX for loading and validating model files
- Google GenAI for explaining the compatibility results
- Pandas for formatting the output tables

## Run with Docker

### Prerequisites

- Docker installed and running
- a Gemini API key available as `GEMINI_API_KEY`

### Start the app

```bash
cd agent-toolchain-advisor
docker build -t edge-toolchain-advisor .
docker run -p 7863:7863 -e GEMINI_API_KEY=your_key_here edge-toolchain-advisor
```

Open http://localhost:7863 in a browser and upload an ONNX model.

## Notes

- The support reference is curated and should be verified against the exact runtime version you plan to use.
- Operators that are not covered by the reference table are marked as unknown rather than assumed supported.
- This app evaluates compatibility from operator names; it does not run a real conversion pipeline.
- The container exposes port `7863` by default.
